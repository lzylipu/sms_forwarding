短信转发器 · 在线刷固件

ESP32-C3 SuperMini + ML307R-DC　无需安装 IDE

1准备

用 Chrome / Edge 打开本页（Safari 与 Firefox 不支持 Web Serial）。用 USB-C 线把设备接到电脑，线要能传数据，只能充电的线不行。

芯片ESP32-C3（4MB Flash） 串口设备管理器里应出现新的 COM 口（macOS 为 /dev/cu.usbmodem*）

2刷入固件

点击下面的按钮 → 选择串口 → 开始安装。整片写入约 1–2 分钟。

当前浏览器不支持 Web Serial，请换 Chrome / Edge 页面不在安全上下文（需 https 或 localhost）
刷的就是 Releases 里那个 sms_forwarding.bin
整个固件只有一个文件 sms_forwarding.bin：在线刷写用它在 0x0 整片写入；以后升级不用插线，设备网页「固件升级」上传同一个文件即可。

3配网

  • 刷完后设备自动重启，因为里面没有任何 WiFi 信息，会立刻开一个无密码热点 SMS-FWD-XXXX
  • 手机连这个热点，浏览器打开 http://192.168.4.1，直接进入配网页
  • 扫描 → 选 2.4G 网络（只支持 2.4G）→ 填密码 → 连接并保存
  • 成功后设备重启并连上你家 WiFi，热点自动关闭，页面显示新 IP
  • 用这个 IP 打开管理页，会先到登录页：账号 admin，密码 admin123（登录后请改）

4以后升级

不用再插 USB：在 Releases 里下载同一个 sms_forwarding.bin，打开设备网页 →「固件升级」→ 选择文件 → 开始升级。设备会自动跳过整包前面的 64KB，只把应用写进另一个槽；连续 3 次启动失败自动回滚到旧版本。

手动刷写：esptool --chip esp32c3 -p <端口> write_flash 0x0 sms_forwarding.bin
